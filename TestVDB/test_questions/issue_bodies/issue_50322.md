### Current Behavior


Dropping a **non-existent** collection returns `{"code": 0, "data": {}}` instead of the documented `code=4` (CollectionNotExists).

```
POST /v2/vectordb/collections/drop
{"collectionName": "nonexistent_collection_xyz", "dbName": "default"}

Response: {"code": 0, "data": {}}
```

### Expected Behavior

Return `code=4` (CollectionNotExists) with a clear error message. The REST API error code documentation defines code=4 for this case.

### Steps To Reproduce

```markdown
import requests
r = requests.post("http://localhost:19530/v2/vectordb/collections/drop",
    json={"collectionName": "nonexistent_xyz", "dbName": "default"},
    headers={"Content-Type": "application/json"})
print(r.json())  # {"code": 0, "data": {}} ← BUG
```
