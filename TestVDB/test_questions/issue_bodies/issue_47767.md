### Current Behavior

Milvus v2.6.10 accepts an empty query vector `[]` when performing search operations, which violates the documented requirement that vector dimensions must be greater than zero and query vectors must match the collection dimension.

### Expected Behavior

Search should fail with a clear error message indicating that query vector cannot be empty and must match the collection dimension.

Example expected error:
```
<ParamError: (code=1100, message=Invalid search parameter 'query_vector': vector cannot be empty, expected dimension 2)>
```

### Anything else?

According to the official Milvus documentation:

**1. Vector Dimension Must Be Greater Than Zero:**

From Milvus Java SDK API Reference - FieldType.Builder.withDimension():

> **withDimension(Integer dimension)**
>
> "Sets the dimension of a vector field. **The dimension value must be greater than zero.** This method internally calls addTypeParam() to store the dimension value."

**Source URL:** https://milvus.io/api-reference/java/v2.4.x/v1/Collection/createCollection.md

**2. Query Vector Dimension Must Match Collection Dimension:**

From Milvus Binary Vector Documentation:

> "During search operations, binary vectors must also be provided in the form of a byte array. **Ensure that the dimensionality of the query vector matches the dimension specified when defining dim** and that every 8 boolean values are converted into 1 byte."

**Source URL:** https://milvus.io/docs/binary-vector.md

**3. Dense Vectors Have Fixed Length:**

From Milvus Dense Vector Documentation:

> "Dense vectors are typically represented as **arrays of floating-point numbers with a fixed length**, such as [0.2, 0.7, 0.1, 0.8, 0.3, ..., 0.5]. The dimensionality of these vectors usually ranges from hundreds to thousands, such as 128, 256, 768, or 1024."

**Source URL:** https://milvus.io/docs/dense-vector.md

**Evidence Analysis:**
1. **Dimension Requirement**: Documentation explicitly states that vector dimension must be greater than zero
2. **Query Matching**: Query vector dimensionality must match the dimension specified in collection schema
3. **Empty Vector Violation**: An empty vector `[]` has dimension 0, which violates both requirements above
4. **Validation Expectation**: The documentation implies that dimension validation should occur during search operations

### Impact

- **Incorrect Search Behavior**: Searching with empty vector may lead to undefined behavior or incorrect results
- **User Confusion**: Users may perform searches with invalid parameters without realizing the parameter is invalid
- **Documentation Violation**: Actual behavior contradicts documented requirements
