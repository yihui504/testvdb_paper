# Content Analysis Guide - Machine Learning

## Purpose
Extract key information from research materials to prepare for ML paper writing.

## What to Extract
### 1. Research Context: Background (current state, existing methods), Motivation, Challenge (scalability, data efficiency, generalization)
### 2. Contribution: Key Contribution, Novelty
### 3. Technical Details
**Problem Formulation**: Task definition, Input/output specification, Assumptions and constraints
**Methodology**: Model architecture, Training procedure, Loss functions, Key algorithmic innovations
**Experiments**: Datasets, Baselines, Metrics (accuracy, F1, BLEU, etc.), Ablation studies, Key results
### 4. Metadata: Target venue, page limit, domain

## ML Conventions
- Report standard deviations for all metrics
- Include computational cost (FLOPs, training time, GPU hours)
- Clearly state hyperparameters and search strategy
- Provide ablation studies for each component
- Compare against recent SOTA methods
