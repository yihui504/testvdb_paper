# Content Analysis Guide - Law

## Purpose
Extract and organize key information from legal research materials. Focus on legal institutions, normative arguments, and doctrinal structure.

## What to Extract
### 1. Institutional Analysis (External System)
- Current Framework: Applicable statutes, regulations, judicial interpretations (specific article numbers, enacted dates)
- Inter-law Relationships: How different laws interact, hierarchy (Constitution > statute > regulation > interpretation)
- Historical Evolution: Legislative history, amendments, drafting intent

### 2. Value Analysis (Internal System)
- Values Behind Institutions: Fairness, efficiency, public interest, autonomy
- Value Tensions: Conflicts between competing principles
- Priority Justification: Why one value prevails over another
- Liability Principles: Fault-based, strict liability, equitable allocation

### 3. Normative Sources
| Source Type | Authority Level |
|-------------|----------------|
| Constitution | Highest — fundamental rights, structural principles |
| Statutes | Primary — cite with exact article numbers and full text |
| Regulations | Secondary — administrative rules, implementation details |
| Judicial Interpretations | Authoritative — supreme court opinions, guiding cases |
| Scholarly Commentary | Persuasive only — use to support, not as authority |
| Grey Literature | Use cautiously — legislative drafts, policy documents |

### 4. Metadata: Target journal, word/page limit, paper type, footnote format

## Law-Specific Conventions
1. Cite statutes precisely — full article text, not paraphrased
2. Maintain source hierarchy — never cite commentary where statute suffices
3. Separate description from analysis — state the law, then critique
4. Track interpretive methods used — literal, systematic, teleological, constitutional
5. Note jurisdictional scope — which legal system applies
