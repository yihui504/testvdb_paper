# Economics & Management Review Criteria

## Evaluation Dimensions
### 1. Theoretical Contribution (Weight: 25%): Clear theoretical foundation? Hypotheses logically derived? Contribution to existing debate articulated? Scoring: 1-5
### 2. Empirical Rigor (Weight: 30%): Data source authoritative? Endogeneity addressed with credible strategy? IV exclusion restriction justified? DID parallel trends verified? Robustness checks sufficient? Mechanism/channel analysis? Scoring: 1-5
### 3. Results Interpretation (Weight: 25%): Economic significance reported (not just p-values)? Coefficient magnitudes interpreted in practical terms? Data values logically consistent? Variable names consistent? Robustness results consistent? Scoring: 1-5
### 4. Presentation Quality (Weight: 20%): Natural academic language (no AI flavor)? Tables properly formatted? Consistent notation? Appropriate length? Scoring: 1-5

## Required Sections (Empirical Economics/Management Papers)
1. Abstract / 2. Introduction / 3. Literature Review & Hypothesis Development / 4. Research Design (data, variables, model, endogeneity) / 5. Empirical Results (baseline, endogeneity tests, robustness, mechanism) / 6. Discussion / 7. Conclusion

## Critical Red Flags
**Major (likely reject)**: No endogeneity handling in causal claims, hypotheses without theoretical grounding, only statistical significance reported, inconsistent variable names, implausible data values, obvious AI-generated language
**Minor (R&R)**: Insufficient robustness checks, weak instrument justification, missing key references, thin discussion, control variables not justified

## Anti-AI Writing Checklist
- No generic filler phrases ("in today's rapidly changing world")
- Field-specific jargon used naturally
- Regression interpretation includes domain-specific meaning
- Writing has appropriate imperfection and author voice
- Transitions feel organic, not templated
