# 公式排版规范

## 通用原则
1. **重要公式编号**：关键公式用 equation 环境（有编号），推导中间步骤用 align 的 \notag
2. **符号一致**：全文同一概念同一符号，首次出现后定义
3. **对齐**：多行公式在 = 或关系符号处对齐
4. **括号匹配**：用 \left( \right) 或 \bigl( \bigr) 适配大小
5. **文字与公式衔接**：公式是句子的一部分，需要标点
