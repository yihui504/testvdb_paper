# Content Analysis Guide - General

## Purpose
Extract key information from user's research materials to prepare for academic paper writing.
This is a fallback domain for papers that don't fit software-engineering or machine-learning.

## What to Extract
### 1. Research Context: Background, Motivation, Challenge
### 2. Contribution: Key Contribution, Novelty
### 3. Technical Details: Methodology (approach/method, key techniques, data), Findings (main results, key insights)
### 4. Metadata: Target venue, page limit, domain

## How to Extract
1. Read all materials in resources/ folder
2. For each dimension: search for relevant content, quote or summarize, note confidence (high/medium/low), note source
3. If information is missing: mark as NOT FOUND, ask user
4. Output: Papers → .self_xept/references.md (## Literature Index), Non-papers → .self_xept/references.md (## Materials)
