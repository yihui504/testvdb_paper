# Post-Write Check

## Purpose
Mandatory checklist to execute after **every** write operation.

## Checklist
### 1. LaTeX Format
| Check | Rule |
|-------|------|
| Citation spacing | Use ~\cite{} (non-breaking space) |
| Reference spacing | Use ~\ref{} |
| Environment closure | Every \begin{} has matching \end{} |
| No orphan commands | All \label{} have corresponding \ref{} |

### 2. Academic Writing Style
| Check | Avoid | Prefer |
|-------|-------|--------|
| Em-dash / En-dash | — or – | Commas, parentheses, separate sentences |
| Sentence length | > 25 words | Break into shorter sentences |
| Weak openings | "It is...", "There is/are..." | Direct subject-verb |
| Nominalizations | "conduct an analysis", "make a comparison" | "analyze", "compare" |
| Hedge clusters | "somewhat relatively fairly" | One hedge word max |

### 3. Citation Standards: Claims need support / Citation at end of sentence / No broken refs / Consistent style
### 4. Consistency: Terminology / Abbreviations / Tense / Naming / Numbers
### 5. Paragraph Structure: Topic sentence / Logical flow / Transitions / 3-8 sentences / One idea

## Quick Reference Card
