# Conciseness Guidelines

## Core Principle
Conciseness means removing **redundancy without losing substance**. Cut the fat, not the meat.

## What to Cut First (Priority Order)
| Priority | Target | Description |
|----------|--------|-------------|
| 1 | Repeated points | Same idea stated in different paragraphs |
| 2 | Filler phrases | "It is worth noting that", "It goes without saying" |
| 3 | Redundant examples | Three examples where one suffices |
| 4 | Excessive background | Introduction content unrelated to core problem |
| 5 | Over-detailed related work | Each cited paper needs only key difference |

## Never Cut
- Core experimental results and data
- Key methodological steps (affects reproducibility)
- Threats to Validity (reviewers check for this)
- Content that reviewers previously requested to add

## Sentence-Level Techniques
- Passive → active: "It was observed that X increased" → "X increased"
- Remove hedge stacking: "It is possible that this might potentially" → "This may"
- Merge short sentences: "We did X. Then we did Y. Then we did Z." → "We sequentially applied X, Y, and Z."

## Paragraph-Level Techniques
- Merge 2-3 discussion paragraphs into one core-argument paragraph
- Replace verbose prose comparisons with a table
- Convert long enumerations to compact inline lists

## Section-Level Techniques
- Related Work: one paragraph per sub-topic, not one per paper
- Background: keep only what's necessary to understand this paper
- Long Discussion: consider merging into Results
