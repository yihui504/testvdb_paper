# Citation Guidelines

## Core Principle
**Never fabricate references.** This is the most serious error in academic writing.

## Citation Source Rules
1. Only cite what the user has provided — from resources/, bib files, or references the user explicitly mentioned
2. Don't generate citations from thin air
3. Flag uncertainty — mark unverifiable citations with [needs verification]
4. Use the add_citation skill for new references

## Format Rules
### LaTeX Citation Commands
- ~\cite{key} — tilde prevents line break; this is the standard form
- Multiple citations: ~\cite{key1,key2,key3} — comma-separated, no spaces
- natbib: use \citep{} (parenthetical) or \citet{} (textual)

### Citation Placement
- Place citations immediately after the claim they support
- One claim, one citation — don't pile 5-6 references without explaining relevance

### Citation Protection During Polishing/Translation
- Don't modify existing \cite{} commands
- Don't change citation format
- Don't add unsolicited citations
