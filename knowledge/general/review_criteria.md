# General Review Criteria

Use this for papers that don't fit SE or ML domains.

## Evaluation Dimensions
### 1. Novelty (Weight: 25%): Is the contribution new? Check: Novel idea/method/finding? Clear contribution? Significance explained? Scoring: 1-5
### 2. Soundness (Weight: 30%): Is methodology sound? Check: Appropriate methodology? Logic valid? Evidence supports conclusions? Scoring: 1-5
### 3. Significance (Weight: 25%): Does it matter? Check: Important problem? Useful to community? Potential impact? Scoring: 1-5
### 4. Presentation (Weight: 20%): Is it well-written? Check: Clear and readable? Well-organized? Figures/tables helpful? Scoring: 1-5

## Required Sections
1. Abstract / 2. Introduction / 3. Method/Approach / 4. Results/Findings / 5. Discussion (optional) / 6. Related Work / 7. Conclusion

## Common Issues
- Unclear contribution / Weak motivation / Insufficient evidence / Poor organization / Missing related work
