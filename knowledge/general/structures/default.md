# Writing Plan Template - General

## Purpose
Create a structural blueprint for the paper. This is meta-level planning — you're NOT writing content here, just planning where it will go.

## Length Constraint
**CRITICAL**: Paper MUST fit within {page_limit} pages. Plan accordingly!

## Section Blueprint

### 1. Introduction (~1-2 pages)
**Structure**: Context and background / Problem statement / research gap / Research objectives / Contributions overview / Paper organization

### 2. Background / Literature Review (~1-2 pages)
**Structure**: Relevant prior work / Theoretical foundation / Key concepts

### 3. Methodology (~2-3 pages)
**Structure**: Research design / Data collection / Analysis methods / Validation approach

### 4. Results (~2-3 pages)
**Structure**: Main findings / Supporting evidence / Analysis of results

### 5. Discussion (~1-2 pages)
**Structure**: Interpretation of results / Comparison with prior work / Implications / Limitations

### 6. Conclusion (~0.5-1 page)
**Structure**: Summary / Key takeaways / Future work

## Output
Write detailed plan to .self_xept/outline.md
