# Education Review Criteria

## Evaluation Dimensions
### 1. Theoretical Grounding (Weight: 20%): Named framework with proper citation? Constructs defined using theory's own terminology? Terminology consistent? Framework connects to RQs? Scoring: 1-5. Key pitfall: mixed terminology signals conceptual confusion.
### 2. Methodological Rigor (Weight: 30%): Design type stated and justified? Quasi-experimental limitations acknowledged? Group equivalence tested? Instruments have current-sample reliability? Normality tested? Full statistics: test name, statistic, df, p-value, effect size? Mediation uses Bootstrap (not Sobel)? Scoring: 1-5
### 3. Specificity and Authenticity (Weight: 20%): Teaching cases name specific lessons/texts/units? Intervention described with detail to replicate? Student work examples or instrument items shown? Context clearly described? Scoring: 1-5
### 4. Data-Interpretation Distinction (Weight: 15%): Results reports data without interpretive claims? Discussion clearly marks interpretation? Claims match design? Non-significant results reported honestly? Paradigm critiques properly qualified? Scoring: 1-5
### 5. Presentation (Weight: 15%): Standard statistical terms used correctly? Tables/figures clear? APA/journal style followed? Logical flow? Scoring: 1-5

## Required Sections (Education Papers)
1. Abstract / 2. Introduction / 3. Literature Review / 4. Methodology / 5. Results / 6. Discussion / 7. Conclusion / 8. References

## Common Issues
**Major**: Claiming causation from quasi-experimental designs, missing effect sizes, inconsistent terminology across frameworks, generic intervention descriptions, mixing statistical paradigms
**Minor**: Paradigm critiques too broad, original instrument reliability cited instead of current-sample alpha, non-standard statistical term translations, missing power analysis

## Paper Types
### Empirical Study (Quantitative): Focus on design rigor, statistical appropriateness, effect sizes. Must have: assumption checks, full reporting, threats to validity.
### Design-Based Research: Focus on iterative design rationale, ecological validity. Must have: design principles, evidence of iteration, practical outcomes.
### Mixed-Methods: Focus on integration of strands. Must have: justification for mixing, clear integration point, both strands rigorous.
