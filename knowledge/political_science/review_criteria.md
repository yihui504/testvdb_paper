# Political Science Review Criteria

## Evaluation Dimensions
### 1. Theoretical Contribution (Weight: 30%): Engages with existing theory (not just topic)? Clear what paper extends, corrects, or transcends? Contribution is specific? Differentiates from closest existing work by name? Scoring: 1-5
### 2. Causal Argument & Mechanism (Weight: 25%): Causal chain is A-->B-->C (not A-->C)? Each link independently argued? Boundary conditions stated? Alternative explanations addressed? Max 4 core concepts with inter-relationships? Red flags: checklist taxonomy, causal mechanism asserted but not argued step-by-step, no scope conditions. Scoring: 1-5
### 3. Research Design & Evidence (Weight: 25%): Case selection method named and justified? Cases map to framework? Cross-case comparability explained? Evidence strategy appropriate? Case analysis structured by framework? Red flags: selection on DV without justification, cross-chapter framework disconnect, entirely secondary sources for process-tracing. Scoring: 1-5
### 4. Presentation & Writing (Weight: 20%): Introduction starts with puzzle, not topic? Literature review by theme, not author? Framework is a diagram, not just text? Conclusion restates contribution precisely? Scoring: 1-5

## Required Sections (Political Science Papers)
1. Abstract / 2. Introduction (puzzle, gap, argument, contributions) / 3. Literature Review / Theoretical Context / 4. Theoretical Framework (concepts, mechanism, propositions) / 5. Research Design / Case Selection / 6. Empirical Analysis (structured by framework) / 7. Discussion / 8. Conclusion

## Common Issues
**Major**: Framework is a taxonomy not theory, reads like policy report, causal black box (A→C without B), case analysis disconnects from framework, contribution vague
**Minor**: Literature by author not theme, missing framework diagram, scope conditions not explicit, over-long policy recommendations, alternative explanations not seriously engaged

## Paper Types
### Theory-Building: Focus on novel framework, causal mechanism, observable implications. Must have: clear theoretical departure, testable propositions.
### Comparative Case Study: Focus on case selection logic, cross-case analysis, framework correspondence. Must have: named comparison method, case-to-framework mapping table.
### Single Case Study / Process Tracing: Focus on within-case causal mechanism, evidence quality. Must have: explicit evidence hierarchy, detailed causal narrative.
