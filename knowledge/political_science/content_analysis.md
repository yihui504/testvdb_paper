# Content Analysis Guide - Political Science

## Purpose
Extract and organize key information from research materials. Focus on theoretical positioning and causal mechanisms — not description.

## What to Extract
### 1. Theoretical Context: Dialogue Theory (which existing theory does this engage?), Theoretical Gap (what does existing theory miss?), Positioning (extend, correct, or transcend?)
### 2. Conceptual Framework: Core Concepts (max 4 — more signals a taxonomy, not theory), Inter-Concept Relations (tensions, reinforcements, trade-offs), Multi-Layer Structure (institutional basis, functional intermediary, developmental outcome)
### 3. Causal Mechanism: Causal Chain (A leads to B leads to C — each link separately argued), Boundary Conditions (when does mechanism apply/fail?), Alternative Explanations (must be explicitly addressed)
### 4. Case & Evidence: Case selection logic, Case-to-framework correspondence, Cross-case comparability justification, Data sources (interviews, archives, process tracing, surveys)
### 5. Metadata: Target venue (APSR, CPS, World Politics, AJPS), Subfield, Method type

## Red-Flag Check
- Framework has 5+ dimensions (likely checklist taxonomy, not theory)
- Reads like a policy report — description without analytical depth
- Causal claims jump from A to C without B
- Case analysis doesn't map back to framework concepts
