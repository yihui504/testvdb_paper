# Communication Review Criteria

## Evaluation Dimensions
### 1. Theoretical Contribution (Weight: 25%): Framework named, cited, and applied? Extend, complicate, or challenge existing theory? Theory appropriate for phenomenon? Scoring: 1-5
### 2. Argument and Analysis (Weight: 30%): Argument stated explicitly? Evidence supports claims (not just illustrates)? De-naturalization present? Information density high? Qualitative data embedded with source tags? Scoring: 1-5
### 3. Literature Engagement (Weight: 20%): Key works cited? Review synthesizes (not lists)? Multiple perspectives compared? Review anchors RQ? Horizontal-vertical structure present? Scoring: 1-5
### 4. Methodological Rigor (Weight: 15%): Paradigm stated? Data collection specific? Analytical method step-by-step? Reflexivity/positionality addressed? Ethical considerations? Scoring: 1-5
### 5. Writing Quality (Weight: 10%): Information density high? Structure logical? Transitions smooth? Jargon explained? Scoring: 1-5

## Required Sections (Communication Papers)
1. Abstract / 2. Introduction / 3. Literature Review (horizontal-vertical interlacing) / 4. Theoretical Framework / 5. Methodology (paradigm, data, analysis, reflexivity) / 6. Findings/Analysis/ 7. Discussion / 8. Conclusion

## Common Issues
**Major**: No clear argument, theory named but not applied, literature review lists without synthesis, low information density, findings without interpretation
**Minor**: Missing reflexivity, insufficient participant/corpus details, theory introduced late, weak conclusion

## Paper Types
### Empirical (Qualitative): Focus on depth of analysis, evidence-argument connection. Must have: clear method, embedded data with source tags, theoretical lens.
### Empirical (Quantitative/Mixed): Focus on measurement validity, appropriate statistics. Must have: operationalization, sample description, effect sizes.
### Theoretical/Critical Essay: Focus on originality, depth of engagement with prior theory. Must have: clear intervention, sustained reasoning.
### Textual/Discourse Analysis: Focus on rigor of reading, text-context connection. Must have: defined corpus, analytical method, theoretical grounding.
