# Content Analysis Guide - Communication / Media Studies

## Purpose
Extract and organize key information from research materials (interview transcripts, field notes, media texts, survey data). Focus on interpreting significance, not summarizing content.

## What to Extract
### 1. Research Context: Phenomenon (cultural/communicative practice), De-naturalization (evidence of historical contingency), Theoretical Lens (named theory with origin citation), Stakes (why this matters socially/politically/culturally)
### 2. Contribution: Key Argument (central claim), Intervention (what gap this fills), Significance (what changes if we accept this argument)
### 3. Evidence & Method
**Qualitative Data**: Interview excerpts with participant tags, Field note passages with dates/settings, Media text samples with source attribution, Coding scheme
**Methodological Details**: Paradigm (interpretive, critical, post-structural), Method (ethnography, discourse analysis, content analysis, interviews), Sampling strategy and demographics, Analytical procedure
### 4. Metadata: Target venue, word limit, paper type

## Communication Conventions
1. De-naturalize — show phenomenon is constructed, not given
2. Name theories explicitly — cite origin, then apply
3. High information density — every sentence must advance argument
4. Embed evidence — qualitative data with source tags
5. Present significance, not just findings
