# 学位论文通用知识

## 查重与AIGC检测要求

| 层次 | 查重率上限 | AIGC率上限 | 检测系统 |
|------|-----------|-----------|----------|
| 本科 | ≤30% | ≤50% | 知网PMLC / 维普 |
| 硕士 | ≤20% | ≤30% | 知网AMLC / 万方 |
| 博士 | ≤15% | ≤30% | 知网VIP |

注：各校标准有差异，以学校最新文件为准。部分学校尚未正式执行AIGC检测，但趋势明确。

## 导师意见处理

1. **转述而非复制**：导师口头意见需转化为学术表述，不要原文搬运微信/邮件措辞
2. **上传修改说明**：每次提交修改稿时附修改说明表，逐条回应导师意见
3. **风格偏好**：了解导师对行文风格的偏好（简洁 vs 详细、是否接受第一人称、是否偏好长句）
4. **多轮修改**：通常需要3-5轮修改，每轮聚焦不同层面（结构->论证->语言->格式）

## 格式规范（通用参考）

| 项目 | 规范 |
|------|------|
| 中文正文 | 宋体，小四（12pt） |
| 中文标题 | 黑体（各级别字号见学校模板） |
| 英文/数字 | Times New Roman |
| 行距 | 1.5倍行距（正文），单倍行距（脚注/参考文献） |
| 页边距 | 上2.5cm 下2.5cm 左3cm 右2.5cm（装订侧加宽） |
| 参考文献格式 | GB/T 7714-2015 |
| 脚注 | 每页重新编号，宋体小五 |

## 通用论文结构

1. 绪论/引言（问题提出、研究意义、文献综述、研究方法、结构安排）
2. 理论基础/概念界定
3. 主体章节（2-4章，按逻辑或案例组织）
4. 结论（研究发现、不足与展望）

## 常见问题

| 问题 | 表现 | 解决方式 |
|------|------|----------|
| 选题太大 | 标题含"研究""探析"但无限定 | 加限定条件：时间、地域、行业、视角 |
| 综述堆砌 | 文献综述逐篇罗列，无分类评述 | 按主题/流派/争议焦点分组评述 |
| 理论与案例脱节 | 理论章和案例章各说各话 | 用理论框架的要素组织案例分析 |
| 结论空泛 | "本文研究了……，具有重要意义" | 列出具体发现（带数据/论据），明确指出局限 |
| 参考文献陈旧 | 引用集中在5年前 | 补充近3年核心期刊文献 |
| 格式不统一 | 标题编号、引用格式前后不一致 | 使用学校模板，最后统一检查 |
