# 硕士学位论文

## 基本要求

| 项目 | 要求 |
|------|------|
| 字数 | 30000-50000字（不含附录、参考文献） |
| 查重率 | ≤20% |
| AIGC率 | ≤30% |
| 参考文献 | 30-80篇，外文文献≥20%，近5年文献≥40% |
| 审核 | 盲审 + 答辩 |

## 方法论要求

- 需明确说明研究方法的选择理由（为什么用这个方法而非其他）
- 定量研究需报告样本量、抽样方式、信效度检验
- 定性研究需说明资料收集过程、编码方式、可信度保障措施
- 混合方法需说明两种方法的结合逻辑和执行顺序

## 盲审关注点

1. **选题的学术价值**：是否有明确的研究问题，问题是否值得研究
2. **文献综述的系统性**：是否涵盖了主要流派和前沿进展，是否有评述而非罗列
3. **研究设计的合理性**：方法与问题是否匹配，数据是否足以支撑结论
4. **论证的逻辑性**：各章节是否环环相扣，论据是否充分
5. **写作的规范性**：格式、引用、语言是否达到学术标准

## 常见盲审意见

| 意见 | 含义 | 应对 |
|------|------|------|
| "文献综述有待深化" | 综述只罗列未评述，或遗漏重要文献 | 按研究主题分组，每组结尾加评述，补充遗漏文献 |
| "研究方法论证不足" | 没有解释为什么选这个方法 | 加一段方法选择的理由，对比其他方法的优劣 |
| "理论与实证结合不够紧密" | 理论框架和后续分析各说各话 | 用理论框架的核心概念/维度组织实证章节 |
| "结论缺乏针对性" | 结论太泛，不是从本研究直接得出的 | 结论严格对应研究问题，每个发现附具体证据 |

## 时间规划参考

| 阶段 | 时长 | 产出 |
|------|------|------|
| 开题 | 1-2个月 | 开题报告 |
| 文献+框架 | 1-2个月 | 综述初稿+研究设计 |
| 数据收集/分析 | 2-3个月 | 数据/案例分析 |
| 初稿撰写 | 2-3个月 | 全文初稿 |
| 修改+盲审 | 2-3个月 | 定稿 |
| 答辩准备 | 2周 | PPT+预答辩 |
