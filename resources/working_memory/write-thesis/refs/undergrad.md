# 本科学位论文

## 基本要求

| 项目 | 要求 |
|------|------|
| 字数 | 8000-15000字（不含附录、参考文献） |
| 查重率 | ≤30% |
| AIGC率 | ≤50% |
| 参考文献 | 15-30篇，近5年文献≥30% |
| 答辩 | 1轮（通常15-20分钟，含陈述+提问） |

## 特点与容许度

- **方法简单OK**：不要求复杂的研究设计，描述性分析、案例分析、文献分析均可
- **用语可适当口语化**：不强求严格的学术腔调，但需避免网络用语和AI味表述
- **理论深度要求较低**：能正确使用1-2个理论框架即可，不要求理论创新
- **数据来源灵活**：二手数据、公开数据、小规模问卷（30份以上）均被接受

## 常见问题与应对

| 问题 | 应对 |
|------|------|
| 选题过大 | 缩小到一个具体问题，加限定词（某地区/某时段/某行业） |
| 文献综述=摘要汇编 | 分类归纳文献，指出已有研究的不足 |
| 全文无自己的观点 | 在分析章节中加入自己的判断，哪怕是小的 |
| 结论抄引言 | 结论写本文具体发现了什么，而非重复研究意义 |
| 参考文献格式混乱 | 统一使用GB/T 7714格式，用Zotero等工具管理 |

## 答辩准备

- 准备5分钟陈述：研究问题->方法->核心发现->结论
- 预判3-5个可能被问的问题（方法选择理由、数据局限、与已有研究的差异）
- 不要在答辩PPT中放大段文字，用图表和关键词
