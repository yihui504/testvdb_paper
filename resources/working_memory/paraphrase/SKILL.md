# Paraphrase（改写降重）

改写选中文字或章节，降低 AI 检测、降查重相似度、或提升自然度——同时保留原义、术语与数据准确。

## 工作流
1. **定范围**：用户选中的文字 / 整节 / "全文"
2. `read` 目标内容
3. **改写**，目标：
   - 保留所有事实主张、数据、引用
   - 保持既有术语与缩写（见 `.self_xept/facts.md`）
   - 变化句式、长度、过渡
   - 把通用/AI 典型措辞换成具体、自然的语言
4. `edit` 应用（逐段以求精确）
5. 报告改了什么

## 改写规则

### 必须保留
- 所有**引用**（`\cite{}`、`~\cite{}`）——绝不删改
- 所有**术语**（见 `.self_xept/facts.md`）——不为既有术语改名
- 所有**缩写**——与其定义保持一致
- 所有**关键数字与数据**——绝不改值
- 所有**技术含义**——换词不得改变所述内容

### 必须改变
- **句首**——避免重复模式（"This"、"The"、"We"）
- **过渡词**——替换套式（"Furthermore"、"Moreover"、"Additionally"）
- **主被动语态**——交替，勿只用一种
- **句长**——长短混搭，打破单一节奏
- **选词**——替换常见 AI 词（"utilize"→"use"、"facilitate"→"help"、"leverage"→"apply"）

### 不要做
- 不要变长（是改写，非扩写）
- 不要加新主张或信息
- 不要删内容
- 不要改段落结构（除非用户要求）
- 不要碰代码块、公式、图
