# RQ2 过滤前后对比表（PPT 唯一保留对比，2026-08-19 整理）

口径说明：
- **过滤前（旧判定链）**：Phase 2 存量三臂实验（sl/vt/fixF，2026-08-16 收口，
  9 轮 × 71 case，GT 45/26 clean_run 口径）
- **过滤后（新判定链）**：ADR-0008 双 Agent（evidence-builder + chain-auditor）+
  机械 A/B 注入 + rework 闭环
  - 无注入（论文 headline）：v7.x 三轮中位 recall 0.705 [0.682, 0.727] / precision 0.775
  - 注入口径（in-sample ablation）：v9 四轮 0.909 / 0.889（逐案四轮一致）
- GT 分母差异披露：旧三臂 = 45 真/26 C 组（clean_run 审定）；新链路 = 44 真/27 FP
  （qdrant_9149 于 Phase 3 证伪 45→44，两处 GT 源已核对零漂移）。跨表对比时
  recall 分母差 1 案（0.578@45 vs 同口径换算 ~0.591@44 系），数字以各自口径为准。

## 三个要点（PPT 讲述用）

1. **架构轴的增益**：同一 71 case 材料只动判定架构（sl→vt→fixF→新链路），
   recall 0.422→0.578→0.705——新链路无注入即超旧最优 +0.127，且方差带宽减半。
2. **注入 ablation 的边界**：考古断言+认知锚点再 +0.204 recall 至 0.909，
   但为 GT-informed in-sample 口径（论文明示），两数字分开呈现。
3. **LLM 边际贡献有界（gates-only）**：纯机械层 0.907/0.886 + 9 悬置，
   LLM 补全悬置案全对、零修正零新增错误——"LLM 判什么"已被机械层覆盖，
   LLM 的实际裁量在"怎么归因"（标签层方差 15–18 案漂移）。
