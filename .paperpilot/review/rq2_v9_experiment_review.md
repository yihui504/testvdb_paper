## Reviewer 1: Domain Expert

**Overall Recommendation:** Weak Accept

### Summary

The materials present the RQ2 experiment section of a study building an LLM-based vector-DB defect-detection pipeline (TestVDB). The core contribution is a *layered* decision architecture that determinizes the contract-grounding (perspective A) and physical/constraint (perspective B) judgment layers with two Python scripts (`check_chain_grounding.py`, `check_physical_constraints.py`), pre-runs them per evidence-chain in the dispatch protocol (`gen_dispatch_v71.py`), and injects the mechanical verdicts into the judge (auditor, per `chain-auditor.md` SOP) so the LLM only explains rather than decides on A-outcome cases. A rework loop absorbs first-round "NEEDS_MORE_EVIDENCE" (NME) drift.

The reported result is that across three full 71-case runs (r1/r2/r3 = v9/v9b/v9c) the *terminal verdict* layer is identical: recall 0.909, precision 0.889, f1 0.899, 71/71 case agreement, "bandwidth 0.000." The experiment's own honest framing is that this is verdict-layer zero variance, **not** LLM-output-layer zero variance: first-run NME varied (7→1→0), `root_cause_if_fp` labels drifted on 15/71 and `fp_evidence_source` on 18/71. The mechanism is broken down as 47/71 verdicts fixed mechanically by A, 15/71 by the SOP grey-zone aggregation rule, 1 by the D cognitive anchor — 63/71 (89%) determined before the auditor session begins — leaving only 8 genuinely-LLM cases. The clean headline (v7.x, three-run median recall 0.705 [0.682,0.727]) is recommended to stay as the paper's headline, with v9 presented as a disclosed GT-informed injection arm ("文档考古断言 + 认知锚点").

### Core Strengths

- **S1:** Layered-migration framing is a genuine methodological insight — judge variance is not claimed to have vanished but is shown to migrate to non-verdict load (NME count, attribution labels), with a concrete mechanism (89% pre-determined) explaining *why* verdict-level agreement obtains. — see 2.1, 2.2
- **S2:** Honesty and disclosure discipline: the injection is explicitly labeled GT-informed, the "zero variance" claim is self-bounded to the verdict layer, and the residual-error narrative (FN violates-mislabel family, FP B-rule2 same-family-different-GT) is surfaced rather than hidden. — see 2.2, 3.2
- **S3:** Strong artifact/process hygiene: leak_scan PASS 15/15 × 3, plugin/script version pinned (cache 2.3.0), rework capped at 3 rounds, verdict JSON paths enumerated, single-instance batch cap ≤12 chains. — see 4.1

### Core Weaknesses

- **W1:** Measurement validity of the injected arm: the v9 numbers (0.909/0.889) are produced by a decision layer whose determinism was *tuned on the GT-derived corpus* (archaeology assertions + cognition anchors derived from the examined issues) and then measured against that same GT — with apparent no held-out split. The 89% mechanical pre-determination is thus partly a regression to the injection data, not independent evidence. — see 1.1, 2.1
- **W2:** Statistical power of "zero variance": only 8/71 verdicts exercise true LLM discretion, so the residual set is N=24 judge decisions across three runs. "Bandwidth 0.000" over the deterministic 63/71 is a claim about determinism-by-construction, not about judge stability; the real stability question is under-powered. — see 2.3, 5.1
- **W3:** Unfair cross-protocol variance comparison: v7.x (clean, no injection) vs v9 (GT-informed injection) differ in both injection and re-run composition; comparing "bandwidth 0.045 → 0.000" as if it measured reduced variance conflates level-shift-by-injection with stability. — see 1.2, 2.3

## Reviewer 2: Area Specialist

**Overall Recommendation:** Accept

### Summary

The material is the candidate RQ2 experimental chapter of an experience paper on **TestVDB**, a multi-agent pipeline that mines historical issues from three vector database systems (Milvus, Qdrant, Weaviate), builds an evidence chain per candidate defect, and routes each chain through an "auditor" agent that applies a four-perspective aggregation (A contract / B physical-semantics / C behavioral / D developer-cognition) to issue a truth verdict. A prior experiment (v7) measured recall ~0.70 with 0.045 bandwidth across three runs, attributing residual variance to LLM judgment. The v9 experiment mechanizes the judgment layer: a main-process pre-run injects the outputs of two deterministic scripts (check_chain_grounding.py for perspective A, check_physical_constraints.py for perspective B) directly into the auditor dispatch packet, plus programmatic claim-anchors and cognitive anchors; the auditor consumes these values without recomputation, reserving LLM discretion for a residual GREY_ZONE. Across three full re-runs (v9/v9b/v9c) of the same 71-case protocol (15-group parallel auditing, capped 3-round rework closed-loop), the verdict layer is reported as 71/71 consistent, zero flip, bandwidth 0.000, recall 0.909 / precision 0.889 / f1 0.899.

The central methodological honesty is that the report refuses to call this "LLM zero-variance." It decomposes variance by layer: the verdict layer is invariant because 89% (63/71) of verdicts are decided before the auditor session begins (66% by mechanical A, 15 by the SOP-aggregate on injected B, one by a D cognitive anchor); meanwhile process NME count still moved 7→1→0, the root_cause_if_fp tag drifted on 15/71, and fp_evidence_source on 18/71. The report frames the result as variance collapsing to non-decision layers, and recommends (rq2_v9_three_runs_report.md lines 66-72) keeping the *uninjected* v7.x three-run median (0.705 / 0.775) as the paper headline and presenting v9 (0.909 / 0.889) as a disclosed GT-informed injection ablation. A secondary finding exposes an open precision risk in mechanical "B-rule-2" (HTTP-semantics): milvus_029 vs milvus_014/028 are physically identical (client parameter error returned as HTTP 200 + business code + server self-proving the value invalid) yet GT marks only 029 a defect.

### Core Strengths

### Summary
