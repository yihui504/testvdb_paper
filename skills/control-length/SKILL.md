# Control Length（控制篇幅）

## 约束类型
`read` `.self_xept/project.yml` 的约束；不清就**问用户并等待**。三种：

| 类型 | 示例 | 怎么测 |
|------|------|--------|
| 字数 | Rebuttal ≤ 700 词 | `read` .tex 直接数字（无需编译） |
| 页数 | 论文 ≤ 8 页 | `pwsh` 跑 `latexmk` → 查 PDF 页数 |
| 分段 | 正文 ≤ 8 页 + refs/附录不限 | `pwsh` 跑 `latexmk` → 查参考文献起始页 |

## 流程
1. 从 `.self_xept/project.yml` 识别约束类型与目标
2. 测当前：
   - 字数 → `read` 文件数
   - 页数 → `pwsh` 跑 `latexmk` 查
3. 算差距（要删/加多少）
4. `edit` → 重测 → 重复到位

## 缩

策略看差距大小：

**小差距**（几行或一段）：仅微调。
- 处理孤行词：若段末行只 1-2 词，调那句把它拉上来——省一整行
- 合并相邻短段，省段间距
- 微缩图表（如 `width=0.45\textwidth` → `0.42`）
- 在 venue 规则内用 `\vspace{-Xpt}` 缩浮动间隙
- 这些保内容，**优先**用

**大差距**（半页以上）：需结构删。
- 删非关键示例/图/表
- 压缩或合并相似子节
- 凭常识排优先——先删低价值内容、保核心论证（领域相关）

## 扩
只加实质内容。绝不掺填充、重复或空话。

## 规则
1. 每轮编辑后：重测（数字数或编译）再宣布完成。
2. 接近目标（~5% 内）用微调（改写、收紧/放松句子）。别做大结构改动。
3. 用 `edit` 做定点改动，别整节重写。
