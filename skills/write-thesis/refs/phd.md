# 博士学位论文

## 基本要求

| 项目 | 要求 |
|------|------|
| 字数 | 80000-150000字（不含附录、参考文献） |
| 查重率 | ≤15% |
| AIGC率 | ≤30% |
| 参考文献 | 80-200+篇，外文文献≥30%，近5年文献≥40% |
| 审核 | 预答辩 -> 外审（盲审） -> 正式答辩 |

## 多轮审核流程

1. **导师审核**：通常5-10轮修改，覆盖结构、论证、语言各层面
2. **课题组/学科组预审**：内部预答辩，暴露主要问题
3. **院系形式审查**：格式、字数、参考文献规范性
4. **外审/盲审**：2-3位校外同行专家匿名评审，任一否决则延期
5. **正式答辩**：5人以上答辩委员会，现场质询

## 原创贡献的四个层面

| 层面 | 说明 | 举例 |
|------|------|------|
| 理论创新 | 提出新概念、新命题或修正已有理论 | 提出"数字劳动权"概念并界定内涵外延 |
| 方法创新 | 将其他领域方法引入本学科，或改进现有方法 | 将计算法学方法应用于合同纠纷类型化分析 |
| 实证发现 | 发现新事实、新规律或推翻已有结论 | 通过裁判文书分析发现某类案件裁判标准存在地区差异 |
| 应用创新 | 为实践提供可操作的方案或制度建议 | 设计平台用工分级分类监管框架 |

至少需要在一个层面有明确贡献，最好在两个层面有所体现。

## 关键检验

- **能否用一句话说清创新点**：如果说不清，说明创新点不够聚焦
- **文献综述是否推导出研究空白**：综述的终点应自然指向你的研究问题
- **核心章节能否独立发表**：博士论文的主体章节应达到期刊论文水平
- **结论是否可证伪**：好的学术结论应有明确的适用条件和边界

## 常见问题

| 问题 | 应对 |
|------|------|
| 创新点表述模糊 | 用"本文首次/区别于已有研究/在X基础上进一步"等句式明确表述 |
| 文献综述与正文脱节 | 综述中每个部分的结论应在正文中被使用或回应 |
| 章节间逻辑断裂 | 每章开头用1-2句话交代与前后章的逻辑关系（但不要用AI式硬过渡） |
| 外审意见严重 | 区分实质性意见和格式意见，集中精力回应实质性问题 |
| 论文太长但不深入 | 删减描述性内容，增加分析深度，质量优先于数量 |

## 参考文献结构建议

| 来源 | 占比建议 |
|------|----------|
| 外文专著/期刊 | ≥30% |
| 中文核心期刊（CSSCI/北核） | ≥40% |
| 学位论文 | ≤10% |
| 政策文件/报告 | 按需，标注发布机构和日期 |
| 网络资源 | 尽量避免，必须时标注访问日期 |
