# Translate Paper（论文翻译）

学术论文学术翻译，保留：学术术语准确性、LaTeX 格式与结构、引用格式（`\cite{}`、`\ref{}`）、数学记号、图表 caption。

**核心原则**：先建术语表，再逐节翻译并报进度。

## 工作流（7 阶段）

### Stage 0: 预分析
1. `read` 项目根源论文
2. 识别文档结构（各节）
3. 数每节词数
4. 检测源语言
5. 问/确认目标语言（停下等待）

### Stage 1: 术语提取
建术语表（先于翻译）：
1. 从论文抽技术术语
2. 查标准译法（领域相关）
3. 含糊术语问用户确认（停下等待）
4. 术语表留上下文供一致使用

### Stage 2: 逐节翻译（核心）
逐节翻译并报进度：
```
[2/8] Translating: Introduction...
```
每节：报进度 → 保留 LaTeX 翻译 → 应用术语表 → `write`/`edit` 保存

### Stage 3: 一致性检查
1. 扫所有已译节
2. 找不一致译法
3. 自动修或标红复核

### Stage 4: 风格打磨
1. 应用目标语言学术风格
2. 修生硬措辞
3. 提升流畅度且保义

### Stage 5: 终审
1. 查引用保留
2. 核完整性
3. 生成摘要

### Stage 6: 编译检查
1. `pwsh` 跑 `latexmk` 编译
2. 修翻译引入的错误
3. 验证目标语言渲染正确
4. 重编译至干净

## 关键规则

### 绝不翻译
- `\cite{...}` — 保留 citation key
- `\ref{}`、`\label{}` — 保留
- 公式内容 — 保留数学记号
- 参考文献里的 BibTeX key
- 自定义 LaTeX 命令名

### 总是翻译
- 节标题（但保留 `\section{}` 命令）
- 图表 caption
- 摘要、正文
- 作者单位（若用户要求）

### 术语处理
1. 翻译前先建术语表
2. 全程用一致术语
3. 含糊术语问用户
4. 术语表留上下文供一致使用

## 常见语言对
- 英 ↔ 中（en-zh、zh-en）
- 英 ↔ 日（en-ja、ja-en）
- 英 ↔ 韩（en-ko、ko-en）
- 英 ↔ 德（en-de、de-en）
